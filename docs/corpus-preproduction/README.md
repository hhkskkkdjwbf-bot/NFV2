# Préproduction des banques natives

Ce dossier contient le registre documentaire des sources candidates, pas les banques de prénoms elles-mêmes.

- `native-bank-source-register.md` : pistes, licences déclarées, limites et décisions par langue.
- `native-bank-sources.json` : version structurée du registre, utilisable par les futurs scripts d'import.
- `SHA256SUMS` : empreintes des fichiers de recherche du dossier.

Aucun fichier brut source ni aucune entrée de prénom n'est inclus dans cette étape. Les empreintes de `SHA256SUMS` ne doivent jamais être présentées comme les empreintes des jeux de données amont. Une source ne passera à l'étape d'import qu'après obtention de son fichier officiel, vérification des conditions de réutilisation et calcul du SHA-256 sur les octets originaux.

Tous les fichiers de prénoms éventuels créés ensuite resteront en préproduction jusqu'à la revue linguistique et juridique.
